# GT 科研与文献工具代码归档库 (GT Research & Literature Code Archive)

本仓库用于集中归档 **GT 项目 / GT文献** 工作流中经过实证验证、可跨会话与跨设备复用的高质量脚本、科研绘图模板、文献检索工具及前端演示组件，用于保存实际采用的项目代码、工具脚本和可复用组件，并记录运行方法与开发进度，方便以后使用和继续开发。

## 从这里开始

- 人工查找代码：先看本页的项目索引，再阅读对应项目的 README。
- AI 接手开发：先阅读 [AGENTS.md](AGENTS.md)，再查看项目说明、变更记录和相关代码。
- 新增项目：参照 [项目说明模板](docs/PROJECT_TEMPLATE.md) 编写项目 README。
- 当前任务与进度：阅读 [2026-10-22 会话交接](docs/SESSION_HANDOFF_2026-10-22.md)。

## 目录结构与模块规划

- `literature-tools/`：学术文献检索、DOI/PMID/arXiv 元数据提取、缓存与 BibTeX 规范化去重脚本
- `scientific-plotting-tools/`：基于 Matplotlib / Seaborn / Plotly 的出版级科研绘图脚本与色盲安全（Okabe-Ito）样式预设
- `frontend-slides-tools/`：零依赖固定 16:9 舞台的本地 HTML 组会与学术汇报演示模板
- `research-ui-design/`：科研数据看板与交互式工具的 UI/UX 组件及无障碍检查辅助脚本
- `utils/`：通用数据处理、统计分析与自动化核验脚本

### 目录约定

| 目录 | 用途 |
| --- | --- |
| `projects/<项目名>/` | 完整项目及其源码、配置示例、运行说明 |
| `snippets/<用途或语言>/` | 可独立复用的小脚本、函数和组件 |
| `docs/` | 通用模板、选型记录和跨项目说明 |

目录在有实际内容时建立；完整项目保留原有内部目录结构。

## 归档与复用规范（v2.14）

1. **优先检索与复用改进**：开发新功能或脚本前，优先检索本仓库及上游开源库中的既有实现并在此基础上改进。
2. **择优自研入库**：当自研代码在简洁度、稳健性或性能上明确优于外部实现，且通过实证核验（`verification-before-completion`）后，自动整理目录结构与使用说明归档至本仓库。
3. **安全与隐私边界**：本仓库仅归档可复用的代码、脚本、样式配置与公开说明文档，不包含未公开的私有研究原始数据、论文手稿正文或任何 API 密钥/凭据。
