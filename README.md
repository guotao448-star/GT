# GT

用于保存实际采用的项目代码、工具脚本和可复用组件，并记录运行方法与开发进度，方便以后使用和继续开发。

## 从这里开始

- 人工查找代码：先看本页的项目索引，再阅读对应项目的 README。
- AI 接手开发：先阅读 [AGENTS.md](AGENTS.md)，再查看项目说明、变更记录和相关代码。
- 新增项目：参照 [项目说明模板](docs/PROJECT_TEMPLATE.md) 编写项目 README。

## 目录约定

| 目录 | 用途 |
| --- | --- |
| `projects/<项目名>/` | 完整项目及其源码、配置示例、运行说明 |
| `snippets/<用途或语言>/` | 可独立复用的小脚本、函数和组件 |
| `docs/` | 通用模板、选型记录和跨项目说明 |

目录在有实际内容时建立；完整项目保留原有内部目录结构。

## 每次保存应附带什么

1. **用途**：解决什么问题，主要功能是什么。
2. **使用方法**：运行环境、安装命令、启动命令和配置示例。
3. **来源**：自编代码或上游仓库链接；第三方代码记录版本、标签或提交 SHA，并保留许可证和版权信息。
4. **修改记录**：在项目的 `CHANGELOG.md` 中记录实际变更。
5. **验证情况**：明确哪些步骤已经验证、哪些尚未验证。
6. **后续工作**：记录已知问题和下一步，方便继续开发。

## 保存约定

用户已于 2026-10-22 约定：后续为用户开发时实际采用、需要保留的代码，默认保存到本仓库，并同步整理说明和索引。仅检索或评估过的项目可记录在选型文档中，无需全部复制。

本仓库当前公开。配置使用占位符或 `.env.example`；密码、API 密钥、登录 Cookie、个人数据和私有材料不提交。依赖安装目录、构建产物和临时文件通常不入库。

第三方代码按各自许可证使用；本仓库不为所有项目统一声明新的开源许可证。
